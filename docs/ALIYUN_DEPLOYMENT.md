# 阿里云大陆服务器部署说明

本项目包含动态作品详情页和 API，不是单纯的静态 HTML，因此优先使用阿里云中国内地轻量应用服务器，而不是直接上传到 OSS。

## 推荐购买配置

- 地域：选择中国内地，优先杭州、上海或深圳
- 系统：Ubuntu LTS
- 配置：2 核 2GB 起步，系统盘 20GB 以上
- 计费：包年包月，并确认该实例支持 ICP 备案
- 带宽：选择带有公网流量包的套餐

不要购买香港或海外地域用于本次备案方案；海外节点不需要 ICP 备案，但不符合“国内稳定访问”的优先目标。

## 服务器上的启动方式

```bash
pnpm install --frozen-lockfile
pnpm run build
pnpm run start
```

生产服务器需要 Node.js 22 或更高版本。正式上线时应使用 Nginx 反向代理，把 80/443 端口转发到应用端口，并配置 HTTPS。

## 上线顺序

1. 购买并实名认证域名。
2. 购买支持备案的中国内地轻量应用服务器。
3. 在阿里云 ICP 备案系统提交个人网站备案。
4. 备案通过后，将域名解析到服务器公网 IP。
5. 上传项目、安装依赖、构建并启动。
6. 配置 HTTPS，并在首页展示 ICP 备案号。

GitHub 仓库继续作为代码和素材备份，不承担最终国内访问服务。
