# 参考站点页面拓扑

## 页面顺序

1. 全屏黑色内容舞台：网格背景与漂浮影像卡片。
2. 顶部覆盖层：左侧品牌标记，中部 `SPIRAL / LIST` 模式提示，右侧菜单按钮。
3. 底部覆盖层：滚动提示与项目数量/分类信息。
4. 影像卡片：点击后进入对应的项目详情页。

## 布局关系

- 页面固定为一屏高度，内容轨道在舞台内部运动，不依赖普通页面滚动高度。
- 网格背景位于内容层之后，顶部和底部信息位于内容层之上。
- 影像墙由多个纵向列组成，每列复制自身内容，轨道循环位移以避免出现空白。
- 3D 平面整体倾斜，卡片保持独立的圆角、阴影和悬浮层级。

## 交互模型

- 时间驱动：多个列以不同速度持续移动。
- 指针驱动：指针位置映射到平面旋转，形成轻微视差。
- 悬停驱动：当前卡片提高亮度、取消遮罩并沿 Z 轴前移。
- 点击驱动：卡片跳转到 `/photography/<slug>` 项目详情页。
- 无真实后端：所有项目来自 `portfolio-data.ts`，媒体地址可随时替换为本地视频。
