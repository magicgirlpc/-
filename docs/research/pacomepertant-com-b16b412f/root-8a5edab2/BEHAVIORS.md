# Behaviors

- Entry: loader covers the viewport. The exact 500×500 reference Lottie autoplays once (67 frames at 25fps); intro copy appears after its SVG DOM is ready, and entry controls become interactive after both page progress and animation completion. Every client-side navigation back to `/` must construct a fresh Lottie instance from frame zero and destroy the previous instance on unmount. A static favicon fallback prevents a blank mark if rendering fails or reduced motion is requested. Either entry choice slides the loader down in about 500ms. Sound entry enables the ambient loop; silent entry keeps it muted.
- Spiral: default active view. It is time-driven even without input. The reference control loop uses `easing = 0.1`, `minWheelSpeed = 0.002`, initial `wheelDirection = 1`, and each animation frame runs `wheelDelta += (targetWheelDelta - wheelDelta) * 0.1`, then `scrollOffset += wheelDelta`; when `abs(targetWheelDelta) < 0.002`, target is restored to `wheelDirection * 0.002`, then multiplied by `0.9`. At 60fps this settles near `0.0018` index/frame (`~0.108` project/second, about 9.26 seconds per project). Mouse wheel adds `deltaY * 0.00015`, clamps target to `[-2, 2]`, and updates the persistent direction. After inertia decays the same slow automatic rotation resumes in the last input direction. Drag and keyboard update the same continuous target. Cards travel along a denser helix (`ANGLE_STEP = .34π`, desktop radius 300–500px and 84px vertical spacing; mobile radius 140–210px and 58px vertical spacing), changing x/y, scale, opacity, blur and z-order. The current or previewed cover retains its lower-left title/lower-right year. Pointer-hover darkens only the hovered cover by 55%, zooms its image to 1.05, and slides a bottom-center white detail pill up from 18px below; the pill contains a 48px thumbnail and the project title and exits upward by 12px. Clicking a card opens the original project link.
- View switch: fixed at desktop `(50%, 45px)`, 18px medium text, 20px gaps and an 8px white dot. Inactive text opacity is 0.4. Labels roll vertically on hover/active over 300ms with the extracted spring easing.
- List/view switch: the top labels roll over `.3s` with the extracted spring. Switching to list fades/scales the spiral toward `translateY(35px) scale(.94)` over `.55s`; after `.2s`, list rows cascade from opacity 0 / `translateY(-30px) scaleY(.5)` to rest over `.5s power3.out`, staggered `.05s` each. Switching back runs the list rows toward opacity 0 / `translateY(50px) scaleY(.5)` over `.3s power3.out` with the same stagger while the spiral simultaneously expands/fades in. Titles are 60px/500 on desktop and 40px on mobile. Hovering one title dims siblings to 0.4 and displays a floating thumbnail that follows the pointer with easing.
- Menu: fixed right/top at the grid margin. Closed pill is roughly 87×48px. It expands to viewport-height minus two margins and 4–6 grid columns wide depending on breakpoint. Duration is 0.9–1s using the extracted spring curve. Drawer links are 80px on desktop with a dot/indent hover.
- Logo: 64×64px at 30px desktop margin. Its tooltip tag scales and rotates into view on hover.
- Showreel: rotated -15deg, 280px wide thumbnail begins partly beyond the lower-left corner; hover rotates to -13deg and scales 1.05 over the spring curve. Perimeter text loops every 12s.
- Sound: 48px white circular button at the lower-right grid margin; inner white disc scales to 0.9 on hover.
- Responsive: under 900px the grid changes from 12 to 6 columns, margin becomes 20px, title size becomes 40px and trail images become 100px. Under 420px margin becomes 15px. The loader, spiral, list, menu, showreel and sound controls stay viewport-bound.
